입력한 가상 매수가·수량·매수 비용과 저장된 검증 가격으로 참고 손익을 계산합니다. 수수료·세금은 해당 기록의 총액을 종목과 같은 통화로 입력하세요. 매도 비용과 배당은 반영하지 않습니다. 이 탭의 메모리에만 유지되며 새로고침하면 사라집니다. 기록이 있으면 페이지를 나갈 때 경고를 요청합니다. 브라우저·앱 종료 방식에 따라 경고가 나오지 않을 수 있으니 먼저 아래에서 백업을 직접 저장하세요. 자동 저장하지 않으며 백업을 만들어도 나가기 경고는 유지됩니다.

검증된 기준가격이 없으면 계산하지 않습니다.

조회 기간은 양 끝 날짜를 포함합니다. 계산 기간과 별개입니다.

전체 0건 중 0건 표시

각 종류의 기록은 페이지당 최대 20건씩 표시합니다. 날짜 정렬은 입출금·매도·가정 배당에 적용하며, 같은 날짜는 등록 순서를 유지합니다. 매수는 별도 거래일이 없으므로 등록 순서를 유지하며, 조회 날짜를 지정하면 숨깁니다. 화면 정렬은 계산·백업의 순서를 바꾸지 않습니다. 이전·다음 기록으로 이동하세요. 종목 코드 검색 중에는 종목이 없는 입출금 기록이 숨겨집니다. 입력 점검의 문제 위치로 이동하면 표시 조건을 초기화합니다.

개별 삭제 직후 한 번만 되돌릴 수 있습니다. 다른 기록·입력 변경 또는 모두 비우기는 되돌리기 사본도 지웁니다.

가상 기록 수정

저장 전 수정 내용은 계산·백업에 포함되지 않습니다. 변경 중에는 누적 성과 계산·JSON 백업·CSV 보고서 생성을 진행하지 않으므로 먼저 저장하거나 취소하세요. 다른 기록을 수정하려면 변경한 내용을 먼저 저장하거나 수정 취소를 누르세요. 다른 기록이나 계산 입력을 변경하면 수정 중인 내용은 닫힙니다.

모의 기록 백업·불러오기

사용자가 입력한 가상 기록만 보관합니다. 시세·추천·검증 상태·인증 토큰은 포함하지 않습니다. 파일과 아래 텍스트는 암호화되지 않으며, 직접 저장한 백업은 파일 앱이나 다운로드 폴더에서 삭제해야 합니다. 기기·클라우드 백업 설정에 따라 복사본이 남을 수 있습니다.

앱에서 파일 저장·선택이 지원되지 않으면 백업 텍스트를 복사·붙여넣으세요. 불러오기는 서버로 파일을 업로드하지 않으며, 계산을 누를 때 기존 API로 가상 기록을 전송합니다.

내용을 확인한 뒤 교체해야 현재 기록에 반영됩니다. 불러온 시세는 사용하지 않습니다.

모의 누적 성과 검증

입력한 가상 기록으로 계산합니다. 원주가·기업행동 검증과 같은 기간의 지수가 필요합니다. 가상 매수는 시작 거래일에 이루어진 것으로 계산하며 입력한 매수 비용을 반영합니다. 입출금은 선택한 거래일의 장 시작 전에 반영합니다. 매도 기록과 비용도 누적 성과에 반영합니다. 배당은 아래의 사용자 가상 시나리오로만 추가할 수 있습니다.

입출금은 KRW 누적 성과에만 반영됩니다. 위 종목별 참고 손익과는 별도입니다. 입금은 수익에서 제외하고, 보유 주식을 자동 매도해 출금하지 않습니다.

이 탭의 모의 기록이며 새로고침하면 사라집니다. 누적 성과 계산 시 기존 API로 전송하며 저장하지 않습니다.

가상 매도 기록 (KRW)

시작일 매수 기록의 수량 안에서 매도를 기록합니다. 누적 성과에만 반영하며 위 종목별 참고 손익은 매수 기록 기준입니다. 비용 포함 평균 매수원가로 실현 손익을 계산합니다. 같은 날은 매수 후 매도, 매도끼리는 등록 순서이며 입출금은 매매보다 먼저 반영합니다. 가상 배당은 매매 뒤에 반영합니다.

실제 주문 없이 이 탭에서만 관리하며 계산 요청 시 API에 전송합니다.

가상 배당 시나리오 (KRW)

공식 배당 자료가 아닌 사용자 가정입니다. 세후 순수령 총액을 입력하면 해당 거래일의 매매 뒤에 현금으로 반영합니다. 세율·주당 배당·권리일·수령 자격은 자동 계산하지 않습니다. 전량 매도 후 지급을 가정할 수도 있으며 실제 권리를 확인한 뜻은 아닙니다. 장 시작 전 출금이나 같은 날 매수에는 사용할 수 없습니다. 비거래일은 임의로 옮기지 않습니다.

이 탭에서만 관리하며 계산 시 API에 전송합니다. 가상 배당 포함 결과는 공식 총수익률·지수 초과수익으로 표시하지 않습니다.
