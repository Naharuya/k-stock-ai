## KRX 인증 경로 공식 자료 확인

이는 공식 Open API의 접근 절차 근거다. 이전 `data.krx.co.kr` 웹 조회의 HTTP 400 / LOGOUT가 인증키 만료 때문이라고 특정할 근거는 확보하지 못했다. 웹 세션 만료·접근 권한·요청 정책 등 구체적인 원인은 `UNRESOLVED`로 남긴다. 승인된 인증·이용 권한 확인 전 `AUTH_BLOCKED`를 유지하고 자동 로그인·세션 우회·무한 재시도를 수행하지 않는다.
