# KSTOCK 웹·앱 공통 메뉴

2026-10-20. Onaria의 기능별 그룹, 모바일 전체 메뉴, 키보드 닫기·포커스 복귀 방식을 KSTOCK의 기존 기능에 맞춰 적용했다. 종교·게임·회원가입·탈퇴 기능은 이식하지 않았다.

- 리서치: 홈, 매수·매도 판단, 신호, 인물, 연구, 시장, 후보, 종목, 동종기업 비교.
- 모의 기록·성과: 모의 포트폴리오, 보고서·성과.
- 데이터·설정·이용 안내: 검증 운영, 미국 공시, 출처, 설정·서버 연결, 기존 개인정보 안내.
- 모바일 하단: 홈, 신호, 모의 기록, 연구, 전체 메뉴. 큰 화면은 그룹별 사이드바를 사용한다.

`public/workspace-navigation.js`가 현재 HTML에 존재하는 목적지만 연결한다. 따라서 구형 공개 화면에도 제한된 기존 목적지 메뉴로 적용 가능하다. 개인정보 링크는 원래 화면에서 제공할 때만 노출한다. Android/iOS WebView와 웹에서 같은 HTML/JS/CSS를 사용하며, 인증·기록 저장·실거래 동작은 바꾸지 않는다. 물리 기기 설치 및 운영 배포는 수행하지 않았다. 기존 격리 서버 후보에는 이번 메뉴가 없으므로 실제 전환 전에 새 검토 후보를 만들어야 한다.

검증: 전체 회귀935/Android 계약4 PASS (`master-qa-20261019183253226.json`). 최초 샌드박스 Android 실패는 로컬 소켓 바인딩 제한으로 확인했고 허용 환경에서 재검증했다. Chrome 1440px, Android 360px/iPhone 390px 화면 크기 모의 브라우저29항목 PASS (`workspace-navigation-20261020.json`): 경로, 활성 상태, 모의 화면 이동, 전체 메뉴, Escape·포커스 복귀, 가로 넘침, 런타임 오류 검사. 커밋할 Git 인덱스 파일만 별도 임시 폴더로 추출한 구형 화면도 데스크톱1440px/모바일390px에서 메뉴 생성·존재하는 목적지만 노출·열기·Escape 닫기·런타임 오류 없음 PASS. 실제 모바일 WebView 검증은 NOT RUN. 모바일 전체 메뉴 버튼의 클릭이 바깥 클릭 닫기와 충돌한 문제를 수정했다.

실행: 개발용 Playwright가 필요하다. `KSTOCK_PLAYWRIGHT_MODULE`에 기존 Playwright 모듈 경로를 지정하고 `node scripts/verify-workspace-navigation.cjs`를 실행한다. 운영 의존성은 추가하지 않는다.

커밋 범위는 이번 메뉴 JS/CSS, HTML 로드 태그2개, 브라우저 검증 도구와 이 문서뿐이다. 기존 미커밋 제품·배포 변경은 포함하지 않는다. 운영 전환/서비스 재시작은 후속 명시 승인 전까지 보류한다.
