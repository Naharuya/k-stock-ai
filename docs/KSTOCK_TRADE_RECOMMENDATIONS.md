# 매수·매도 모의 판단 v1

2026-10-19 KST 사용자 승인으로 추천 기능 개발. 실제 주문 활성화 승인은 포함하지 않습니다.

## 화면과 API

- 홈의 ‘매수·매도 판단 확인하기’ 또는 `/#trade-recommendations`.
- GET `/api/v2/recommendations`: 현재 종목의 판단, 기준 시각, 유효 기한, 참고 가격, 검증 체크, 차단 사유와 근거 fingerprint.
- GET API만 추가했습니다. 주문·취소·계좌 변경 경로를 호출하지 않습니다.
- 기존 공식 수집/저장 검증 Worker를 사용합니다. 저장 검증에 종목별 판단을 포함하고 새 조회에서는 현재 기준으로 재계산합니다.

## 분기

| 출력 | 의미 |
| --- | --- |
| BUY | 필수 데이터 및 기존 위원회 조건을 통과한 모의 매수 검토 |
| SELL | 낮은 점수 또는 확인된 위험 조건에 따른 보유 종목 축소 검토. 공매도 지시 아님 |
| WATCH | 자료 조건을 통과했지만 방향성 규칙이 발생하지 않은 관망 |
| INSUFFICIENT_DATA | 자료 부족·미확인·만료. 매도 또는 관망으로 해석하지 않음 |

v1은 **모의 판단 전용**, 예측 성능 미입증입니다. 실제 현재 종목 판단과 ‘가상 조건’ 예시를 별도로 제공합니다. 예시는 실제 종목도, 검증된 투자 성과도 아닙니다.

## 데이터 검증

1. 분석 시각과 최신 가격: 미래 날짜 차단, 기존8일 가격 범위 유지.
2. 공식 원문·D-2 공개 이용 가능 시점·미해결 정정/수집 차단.
3. 연속4분기 재무 및 재무·가격일 정렬을 별도로 검증. 가격이 없다고 확인된 TTM을 지우지 않음.
4. PER/PBR/PSR, 동일일 주식수, 전체 기업행동 근거 검증.
5. 배수별 동종 표본3개와 과거 표본3개 최소 기준 유지.
6. 종합 위험 범위, 필수 지표, 기존 위원회 점수 재계산 대사, 컴플라이언스·검토 상태 확인.
7. 지표는24시간 이내 자료만 사용. 누락 값은0으로 대체하지 않음.

이미 원천 증빙이 검증된 입력을 전달할 수 있도록 평가배수 입력 계약과 보고서 분석 필드를 연결합니다. 현재 수집기가 갖추지 못한 주식수·기업행동·귀속 재무·종합 위험 증빙을 새 기능이 대신 만들어내지 않습니다.

## 규칙의 한계와 유효 기한

- 매수 점수50은 기존 Investment Committee의 조건을 재사용.
- 매도 점수35는 기존 약한 가치평가 검토 경계에서 가져온 **신규 실험 정책**입니다. 반대 근거75/위험 패널티15 경계도 기존 값 재사용. 이 값들이 수익을 예측한다고 검증된 것은 아닙니다.
- 데이터 조건을 먼저 통과해야 규칙을 적용합니다. 사용자 승인은 금융 데이터의 검증 완료와 다릅니다.
- 유효 기한은 생성 후 최대24시간, 지표 최신성 종료, 가격 최신성 종료 중 가장 빠른 시각입니다. 만료되면 화면에서 비활성화합니다. 활성 판단 화면은 기존30초 UI 갱신 주기로 재조회합니다.
- 목표가, 기대수익, 승률은 근거가 없으므로 null. 거래비용/슬리피지 반영 성과나 전략 우월성을 주장하지 않습니다.
- 실제 보유 수량을 수집하거나 매도 가능 수량·자동 주문을 계산하지 않습니다.

## 현재 데이터 판정

2026-10-19 실행 API에서 AAPL/MSFT/NVDA 모두 INSUFFICIENT_DATA입니다. 실제 BUY/SELL0개. 확인된 TTM과 달리 가격/주식수/기업행동/배수/표본/종합 위험/지표 최신성 등의 조건이 아직 충족되지 않았습니다. 실제 화면의 체크를 기준으로 판단하며, 가상 예시를 실제 추천으로 승격하지 않습니다.

다음 개발은 부족한 입력의 공식 검증과 규칙의 독립 표본 평가입니다. 기존 Apple/Samsung 추천 순위·성과 정책과 실거래 OFF를 유지합니다.
