# KSTOCK UI/UX — 5번 시안 참고 반응형 재구성

2026-10-20. 사용자 제공 5번 ARVIA 시안의 보라·라벤더, 부드러운 빛, 여백, 세리프 제목을 참고했다. KSTOCK의 이름과 금융 연구 기능은 유지하고 종교 이미지나 타 브랜드 자산을 복사하지 않았다. 별도 SVG 표식과 CSS 장식을 사용하며 외부 이미지·폰트·추적 요청은 추가하지 않는다.

## 검토 결과와 수정

- 거대한 안내 문구와 중복 상단 버튼 때문에 모바일 콘텐츠 영역이 좁았다. 제목을 줄이고 연구 탐색/모의 기록 두 경로를 우선 배치했다. Android/iOS 상단 연결 도구는 한 줄로 정리했으며 큰 iOS 접근성 글자에서는 세로 배치한다. Android는 정상 웹 화면에서 샘플 분석 버튼을 숨긴다.
- 청색·남색 운영 패널과 여러 스타일의 혼재를 정리했다. 기본 색은 네이비 `#20243D`, 보라 `#6550AD`, 라벤더 `#F0ECFA`, 바탕 `#F7F6FB`다. 다크 모드에서는 밝은 보라와 어두운 바탕을 별도로 사용한다. 오류·수익·보류는 문구와 수치도 함께 표시한다. 색상을 금융자료의 검증 근거처럼 표현하지 않는다.
- 데스크톱은 사이드바와 연구 카드2열, 모바일은 카드1열·하단5메뉴를 사용한다. 320px 요약은1열, 태블릿은 축소 사이드바, 입력 폼은 폭에 따라 줄바꿈한다. 표는 컨테이너 안에서 스크롤한다.
- 로컬 Mac/USB가 앱 접속에 필요하다는 오래된 안내를 바로잡았다. 연구 워커 상태와 운영 화면 연결을 구분한다. 신호/추천/가격근거/HOLD·PENDING 판정은 바꾸지 않는다.
