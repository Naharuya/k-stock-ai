# K-Stock AI 로컬 체험 안내

2026-10-19 KST 확인 기준. 연구 화면을 살펴보는 로컬 검증 버전입니다.

## 지금 열기

- **Mac:** 서버가 실행 중인 Mac의 브라우저에서 <http://127.0.0.1:3000/>를 엽니다.
- **Galaxy A33:** 기존 K-Stock 검증 앱을 엽니다. Mac 서버와 기존 USB 연결이 필요합니다. 서버 재시작 뒤 화면이 비어 있으면 앱의 ‘다시 연결’을 누릅니다. 상단의 ‘샘플 분석 확인’은 예시용이며 실제 종목 자료와 별도입니다.
- iOS는 Simulator에서 검증했습니다. 이번 첫 사용 동선의 iPhone 실기기 검증은 수행하지 않았습니다.

다른 컴퓨터/휴대전화의 localhost는 Mac 주소가 아닙니다. 이번 작업에서는 LAN 공개나 외부 배포를 활성화하지 않았습니다.

## 처음 볼 화면

1. 홈의 **‘처음 사용하기 · 지금 볼 수 있는 기능’**을 펼칩니다.
2. **종목 살펴보기:** AAPL·MSFT·NVDA 등 현재 목록의 기업을 검색합니다. 자료 준비 요약과 ‘자료별 기준일·출처 보기’를 확인합니다. TTM 확인은 투자 추천 통과와 다릅니다.
3. **인물 발언 보기:** 인물을 선택하고 공식 발언·신고 행동을 날짜순으로 살펴봅니다. 관련 기업 버튼은 공식 자료에 명시된 관계만 연결합니다. 기관의 보유 변화는 그 인물 개인의 실제 거래가 아닙니다.
4. **에이전트 보고 보기:** 마지막 작업 완료 시각, 최근 완료 기록, 보류 이유와 다음 실행을 확인합니다. 대기는 실행 중과 다르며, 단계 확인 수는 추천 종목 수나 회귀 테스트 PASS 수가 아닙니다.
5. **연구:** 과거 시장 반응과 초과수익을 살펴봅니다. 과거 연구를 현재 추천으로 읽지 마세요. 연결 실패 시 이전 조회 자료라는 안내가 표시됩니다.

## 매수·매도 판단 화면

홈의 ‘매수·매도 판단 확인하기’를 누르면 종목별 모의 판단과 필요한 근거를 볼 수 있습니다. 현재 실제 종목은 자료 부족이며 매수·매도 검토0개입니다. 별도 ‘가상 조건’은 규칙 시험용으로 실제 추천이 아닙니다. 자세한 정책은 `docs/KSTOCK_TRADE_RECOMMENDATIONS.md`를 참고하세요.

실거래는 OFF입니다. 이 체험에 실제 주문·계좌 변경은 필요하지 않습니다.

## 추천 기능의 시점

첫 체험은 지금 가능하지만 추천 기능 출시일은 확정하지 않았습니다. 동일 기준일 가격·주식수, 기업행동, 귀속 재무 범위, 비교기업 및 위험 검증과 충분한 사후 관측이 필요합니다. 야간 에이전트 실행 횟수나 테스트 수만으로 조건이 충족되지는 않습니다.

최신 검증 결과와 NOT RUN 항목은 `docs/KSTOCK_QA_FOLLOWUP_REPORT.md`에 기록합니다.
