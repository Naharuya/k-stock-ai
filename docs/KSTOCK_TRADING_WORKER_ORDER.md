# Mac mini 시간별 시세 작업 — 매매 정보 제품 우선

사용자 승인: 2026-10-20, 기획에 따른 전 단계 개발·마무리 및 기존 지속 업무 승인.

기존 3600초 LaunchAgent를 재사용한다. 이 문서가 존재하는 동안 시간별 실행은 검증된 제한 읽기 작업을 직접 실행하며, 실패를 반복한 LLM 코드 수정 요청을 자동 재발행하지 않는다. 이미 실행 중인 이전 작업은 강제 종료하지 않는다.

1. scripts/refresh-trading-instruments.py: 하루1회 이내 공식 KIS 마스터6개만 읽어 검색목록·원천해시·제외사유를 갱신. 현재 목록은 공급자 스냅샷이며 거래소 전수대사/전 종목 검증 완료가 아니다.
2. scripts/run-trading-data-cycle.mjs --approved-read-only: 초기 주요종목8개와 전체목록 다음17개, 최대25종목을 시간당1배치로 읽는다. API는 시세·일봉만 허용, 계좌·주문·유료등록·인증우회 금지. 2.1초 간격, 인증/접근 차단이면 배치를 중단하고 체크포인트 보존.
3. 완료 여부와 관계없이 기존 JINI_TO_ARI.md 및 로컬 macmini-hourly 보고 경로로 시각·조회 성공/실패·대상수·고유 시도수·미확인/차단·다음 작업을 보고한다. HTTP 실제 호출수를 계측하지 않으면 null이며 시도수와 구분한다. 보고 전달 실패는 로컬에 남긴다.
4. 기기 저장 사용자 보유·토큰·키를 출력/공유하지 않는다. 공개 시장자료만 파일에 저장한다. 실제 공급자 인증은 프로그램 메모리에서 사용한다.
5. 수집 결과는 로컬 Mac mini에 저장하고 scripts/sync-trading-data.py --publish로 공개 마스터와 최근 최대500종목의 일봉만 기존 운영 서버에 동기화한다. 파일별 스키마·해시 검증과 기존 최신자료 보존을 거친다. KIS 키·사용자 보유·환경·실행 파일은 동기화하지 않는다. 웹 앱은 서버로 동기화된 종가를 표시하며 실시간 시세라고 표현하지 않는다.
6. 연구량 증가보다 실제 조회 가능한 종목과 최신 가격 커버리지, 실제 데이터로 계산 가능한 모의조건이 목표다. 추천 승인/검증된 투자성과/실거래는 계속 HOLD/OFF다.
7. master 오래됨·인증 차단·공급자 제한은 실제 BLOCKED/PARTIAL로 보고한다. 모든 종목 검증 완료까지의 기간을 임의 약속하지 않는다. 종료/잠자기/로그아웃 중 실행을 보장하지 않는다.


## 즉시 조회 연결 보강

com.ari.kstock-market-gateway는 로컬127.0.0.1:18880에만 바인딩하고 기존 SSH로 운영 서버127.0.0.1:18880에 역방향 연결한다. 공개 바인딩·계좌·주문·사용자 보유 전송 없음. 시세 GET2종류와 숫자형 일봉 필드만 통과시키며120요청/시간·직렬2초 간격을 적용한다. 기존 시간별 작업도 이 공유 게이트웨이를 사용해 토큰·호출 정책을 일원화한다. 연결 실패 시 기존 공개 스냅샷과 정확한 시각을 표시하고 최신 세션 미확인은 판단 보류한다. 맥미니가 꺼지면 새 조회가 불가능하다는 의존성은 숨기지 않는다.
