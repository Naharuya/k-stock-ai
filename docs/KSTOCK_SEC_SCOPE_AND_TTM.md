# SEC 원문 범위 검증과 TTM

현재 적용 대상은 사전 고정된 AAPL/MSFT/NVDA다. 회사별 companyfacts에서 얻은 분기 입력을 공식 공시의 XBRL 인스턴스와 대조한다. 다음 조건을 모두 확인해야 연결 범위 검증을 적용한다.

- 같은 발행사 CIK, us-gaap 태그, 시작일·종료일, USD 단위, 금액.
- segment/scenario가 없는 전체 발행사 문맥.
- 같은 공시의 명시적인 연결 손익·현금흐름 제표 표제 또는 회사와 종속기업 포함·내부거래 제거를 명시한 연결 회계정책.
- 공식 SEC 경로·문서번호·SHA256·실제 검증시각. 검증 이후 시점에만 적용한다.

차원이 없다는 이유만으로 연결 범위를 통과시키지 않는다. 연결 흐름 계정 확인은 보통주 귀속 이익·장부가치, 발행주식수, 가격일 주식수 또는 기업행동 전수 검증을 뜻하지 않는다.

`sec-scope-reviews.json`에는 정규화된 사실과 원문 링크·해시·문맥 ID·보고 정밀도를 저장한다. 공시 전문/주소는 이 검증 결과에 저장하지 않는다. `sec-quarter-conflict-review.json`에는 직접 분기와 누적 차감값의 불일치 근거를 보존한다.

기존 공식 수집 Worker는 먼저 기존 작업을 실행하고, 남은 주기 예산 내에서 원문 범위를 최대3HTTP 요청씩 처리한다. 전체 주기 상한12회, 문서 잠금/확보 근거 재사용/실패24시간 대기를 적용한다. 소스가 비활성 또는 미승인이면 호출하지 않는다. 새 타이머나 에이전트를 만들지 않는다.

공식 원문에서 `decimals=-6`이 확인된 각 금액의 반올림 구간을 비교할 수 있으나, 이는 숫자를 보정하거나 차단을 해제하는 정책이 아니다. NVIDIA 100만USD 차이는 이 정밀도와 양립하는 것으로 분류하되 매출·순이익 TTM을 보류한다. 원문 값의 평균/선택/임의 수정은 하지 않는다.

TTM은 기존 분기 연속성·공개시점·12개월 범위 검사를 모두 통과한 경우 항목별로만 표시한다. 글로벌 평가배수는 동일 기준일 원주가/보통주 유통주식수/주식 종류/기업행동 전수/통화·귀속 범위가 필요하다. 관측된 특정일 유통주식수를 오늘 가격에 곱하거나, 유통주식수를 발행주식수로 바꾸지 않는다. PER/PBR/PSR/EV·EBITDA는 독립 보류 판정하며 추천의 비교기업 최소3개 기준도 유지한다.

조사용 재현 CLI는 기존 승인·활성 SEC 경로에서만 실행한다.

```sh
node scripts/collect-sec-scope.mjs AAPL
node scripts/collect-sec-scope.mjs MSFT
node scripts/collect-sec-scope.mjs NVDA
```

CLI도1회최대12HTTP/확보 문서 재사용을 적용한다. 실제 최초 공개 시각이나 투자 전략 예측력이 입증됐다는 뜻이 아니다. 추천·삼성전자 성과·Apple 순위 HOLD 및 실거래 OFF는 별도 Gate로 유지한다.
