# Mac mini 주식수 근거 검증 업무지시 — 2026-10-20 KST

사용자 지시: 미확인 주식수 검증은 Mac mini 백엔드가 맡고, 현재 Codex는 모의 포트폴리오 UI 개발을 진행한다.
기존 KSTOCK_BACKEND_AGENT_DIRECTIVE.md의 안전 규칙을 유지하되 이번 사이클의 우선 업무는 아래 범위로 한정한다.

## 목표와 범위
- Apple 보고기간 2025-09-28~2026-06-27: 발행주식수 14,773,260,000 → 14,608,963,000, 매입·소각 보고 합계 215,000,000, 산술 잔차 +50,703,000주. 이 수치는 인수인계 값이며 저장 공식 근거와 재대조한다.
- SEC 접수 0000320193-26-000020 및 연결 가능한 공식 근거에서 발행·주식보상·원천징수의 수량 정의, 기간, 주식 종류, 공개 시점, 실제 효력일을 확인한다.
- RSU 권리확정 수량을 신주 발행으로 대신 쓰지 않는다. 반올림 정밀도와 잔차를 보존한다. 보고기간 합계로 개별 거래일이나 가격일까지의 수량을 만들지 않는다.
- 나머지 국내 주식수 미확인 항목(SK·DB 등)은 기존 큐에 유지하며 이번 Apple 검증과 섞지 않는다.

## 담당 파일과 협업
- 먼저 AGENTS.md, docs/ARI_COMPLIANCE_STANDARD.md, 본 지시서, 기존 전용 보고서와 저장 근거를 읽고 경로/Git remote/branch/운영 대상/미커밋 상태를 기록한다.
- Mac mini 담당: 저장 근거 조사, 백엔드 검증 및 필요한 fixture 테스트. 변경 전 계획과 실제 변경 파일을 전용 보고서에 적는다.
- public/**, android/**, 모의 포트폴리오 관련 코드, 공통 QA 보고서/개발로그 수정 금지. 별도 전용 보고서 docs/KSTOCK_SHARE_BACKEND_REPORT.md에 append하여 이전 기록 보존.
- 현재 호스트의 미커밋 코드가 Mac mini와 같다고 가정하지 않는다. 누락 파일을 임의 재작성하거나 다른 호스트 데이터를 덮어쓰지 않는다. API 변경은 제안으로 보고한다.

## 실행 및 완료 기준
- 기존 실행기/Worker 재사용, 한 사이클만 수행. HOLD 파일 제거·스케줄/서비스 변경 금지.
- 저장 자료 우선. 기존 허용된 무료 읽기 경로만 사용하고 실행기가 신규 수집을 지원하지 않으면 NOT RUN 및 필요한 소스/실행 경로를 보고한다. 도구 허용 목록 변경이나 우회 금지.
- 실제 수량·기간·원문 URL·문서 식별·원문 해시·수집/검증 시각·정밀도를 근거별로 기록하고, 설명 가능한 잔차와 미설명 잔차를 구분한다. 자료 부족 자체도 보고할 수 있으며 억지 코드 변경 금지.
- 변경에 맞는 fixture 및 허용 kstock-offline-test, git-diff 실행. 명령/실제 PASS·FAIL·NOT RUN과 외부 요청 수 기록. 실행 불가를 성공으로 표기하지 않는다.
- 실거래 OFF, 추천·Apple 가치평가 HOLD 유지. 운영 배포/삭제/인증정보/결제/실주문/다른 프로젝트 변경 금지.
- 최종 상태 PARTIAL/BLOCKED/범위 내 검증 완료를 근거와 함께 기록. 전체 기업행동 커버리지와 효력일이 미확인이면 bridgeEligible=false 유지.
