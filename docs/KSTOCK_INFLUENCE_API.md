# Influence Research API — local v1

`GET /api/v2/influence/research` shares existing `/api` authentication, read-only native transport and `Cache-Control: no-store`. No order, credential update, paid model call or external collection is performed by loading the API.

Fields: success/schemaVersion/status/asOf, people, statements, capitalEvents, signals, marketReaction, validation, collection, analysis, recommendationStatus, samsungPerformanceStatus, liveTradingEnabled. Errors are sanitized 503 INFLUENCE_RESEARCH_UNAVAILABLE; absent source file returns NO_DATA and empty arrays.

People use stable personId and roles with validFrom/validTo/publicAvailableAt and official proof. Initial identities are Jerome Powell and Warren Buffett. roleScope=AT_STATEMENT_ONLY; current offices are not inferred from historical statements. Source roles are only verified for their documented statement date.

Statements distinguish spokenAt (null when exact clock unknown), spokenDate/statementDate, publishedAt, publicationTimePrecision=DAY and publicationAssumption=CONSERVATIVE_END_OF_DAY. Conservative day-end availability is a research cutoff, not the observed publication timestamp. originalTextReference is an official URL/page reference; full copyrighted text is not stored or served. summaryKind=EDITORIAL_SUMMARY is separate from analysis.

Capital events distinguish CONFIRMED_TRANSACTION / REPORTED_HOLDING_CHANGE / ANNOUNCED_INTENTION. Company own actions are actorType COMPANY. Institutions and companies are never treated as personal transactions or automatically combined with a person's statements. 13F requires INSTITUTION, reportingPeriod and nonnegative reported quantity; transactionDate=null. Pending Form4 evidence retains reportedTransactionDate separately while transactionDate=null until raw original verification. Unknown price is null, not zero. Initial saved SEC 1 holding/4 insider records are INSUFFICIENT_DATA because original integrity is not independently connected to this engine. They are visible as pending reports, not signals.

Signals use STATEMENT_ONLY / CAPITAL_ONLY / STATEMENT_CAPITAL_ALIGNED / STATEMENT_CAPITAL_DIVERGENT / INSUFFICIENT_EVIDENCE (legacySignalType retains the old identifiers), evidenceIds and latest publicAvailableAt of all included facts. Personal transactions require the same person and company; institution reports require a separately verified, historically bounded official role relation. Institution/company impersonation is blocked. All signals have researchOnly=true, recommendationStatus=HOLD and bias/causality limitations. Source validation alone is not predictive-signal validation.

Market research measures common verified session windows 1/5/20, baseline first observed close at/after public availability, after-close uses next session. No interpolation/annualization. PRICE_RETURN excludes dividends and costs. Duplicate/missing dates, unknown corporate actions or date-only publication retain HOLD/null; unelapsed windows retain PENDING. Session calendar must explicitly contain open/close instants. Selection/survivorship bias remain NOT_ASSESSED. Appropriate overseas/industry benchmark and historical prices are not connected to initial statements.

`createStatementAnalysis({generate,modelVersion,promptVersion,now})` is an optional injected adapter. Missing provider gives NOT_RUN and no request. Verified reference, date cutoff, model version, grounded evidence ID, structured sentiment/industries/companies/policy/relevance/uncertainty/counter-evidence are required. Output is AI_INFERENCE / UNVERIFIED_INTERPRETATION, hiddenIntent=NOT_ASSERTED, causalClaim=false. Runtime server does not configure an external provider. Mock provider tests do not represent actual model execution.

Existing Peer Validation Scheduler runs savedEvidenceTasks under the same 30-minute interval. INFLUENCE_VALIDATION status/checkedAt/externalRequests is visible in peer-validation/status. Task failure is sanitized and isolated from financial validation; concurrent ticks do not duplicate work. No new Worker, external timer or daemon was created. Loading API also revalidates saved evidence and records fingerprint/lastValidatedAt in process memory; durable curated sources remain in Git-excluded data/v2/influence/sources.json mode0600. Source collection is explicit bounded scripts/collect-influence-official.mjs: 2 fixed official URLs, timeout, size bound, no redirects, 24h cache, no infinite retries. Source checksum and review metadata are persisted; originals are not.

Web and Android WebView use this same API. Person selection, expanded evidence and scroll positions survive refresh; stale state is marked on connection failure. The existing Android native authenticated read contract covers the route. Local validation app retains existing data and installation.

Public profile facts are minimized to documented identity/role/source. No personal contacts, private accounts or user profiles are collected. No external AI transfer happens. Production deployment/store disclosures remain outside this local work; no retention/deletion promise or new account feature is introduced.


## Signal research and local model execution — 2026-10-12

`signalResearch.results` contains the requested signalId/signalType/publicAvailableAt/relatedSecurity/benchmark/horizon/observedReturn/benchmarkReturn/excessReturn/sampleSize/verificationStatus/limitations fields. Fractions are returns, not percentages. Unverified pairs retain null returns and sampleSize=0. Direction agreement requires independently verified statement direction and capital-event direction. Personal transactions require same-person evidence; institution holding comparisons additionally require an official role relation covering both dates. AI sentiment alone cannot establish agreement or personal13F attribution.

Explicit `node scripts/analyze-influence-local.mjs` reads only the two allowlisted official URLs, extracts PDF text in memory with PDFKit, and executes already-installed localhost Ollama qwen3:8b. No API handler or scheduled task invokes a model or external source. Same hash/model/prompt generated results are cached; a revised prompt preserves prior results in private history. Up to30,000 source characters are transient model input, so analysis is a bounded excerpt, not an exhaustive document audit. Source text is not stored or served. Analyses are Git-excluded mode0600, with model digest, prompt version, source hash and timestamps. Saved analysis is accepted only if source, document, allowed companies, prompt and cutoff match. Current model inference is retrospective and never inserted into a historical predictive backtest.

`signalResearch.indexObservation` is separately labeled DESCRIPTIVE_ONLY: actual FRED S&P500 PRICE_INDEX data, first observed close after the conservative publication day, with NYSE2025September1 holiday excluded using official operator evidence. It exposes derived index changes, not raw copyrighted price series, and never fills observedReturn/benchmarkReturn/excessReturn for a missing security pair. `verifiedSignalSamples=0`, causalClaim=false. Official Fed PDF release-on-delivery10amEDT is a scheduled release, not independently observed first website publication/delivery; the original DAY precision is retained.

`workDomains` records six logical areas under the one existing saved-evidence scheduler. Financial queue remains separate, while worker state exposes bounded domain name/status metadata. No new external automatic collection or paid AI execution is enabled.
