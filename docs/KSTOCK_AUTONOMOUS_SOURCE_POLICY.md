수집 순서는 실현 수익률을 확인하기 전에 고정했다. RSS 최신2건 제한으로 전체 영향력 인물 모집단·모든 공식 발언을 전수 수집한다고 주장하지 않는다. 신규 사건 선정과 표본 편향을 표시한다. 실패·무반응·음의 초과수익 기존 사례를 삭제하지 않는다.

주기별 작업 key·content hash·원천 archive로 중복과 정정 이력을 보존한다. 공식 응답 최대2MB, 사이클 실제 외부 fetch 최대12, 출처 간 최소1100ms, 일시 오류만 최대3회 백오프, 인증 차단은 별도 source lock. 같은 자료를 반복 계산하지 않는다. source-gate가 캐시/차단/재시도 상태를 저장하며 Collection Worker의 기존 파일 잠금·작업 복구를 사용한다. Financial Validation은 별도 기존 큐를 유지한다.

신규 공식 원문은 식별/날짜/직책 확인 후 설치된 localhost Ollama qwen3:8b로만 해석한다. 최대2회/30분, 원문 맥락 최대30000자, 생성 타임아웃120초. 기업·거래·숨은 의도·인과·추천을 추론해 사실로 승격하지 않는다. 해석은 AI_INFERENCE/UNVERIFIED_INTERPRETATION으로 표시하며 source/document/model/prompt/version을 기록한다. 새 전체 저작물은 영구 저장·UI 제공하지 않는다. 원문은 일시적 로컬 모델 입력이며 archive는 해시·링크·검증 사실·요약만 저장한다. 원문 hash 변경 시 이전 버전을 보존한다. 모델 실패는 결과별 백오프·상한으로 보류한다. 미설치 모델을 자동 다운로드하거나 유료 모델을 사용하지 않는다.
